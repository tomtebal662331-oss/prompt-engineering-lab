# slide 1

Prompt Engineering Experiment
How Prompt Design Affects Generative AI Output Quality
Evaluation of Zero-shot, Few-shot, and Refined Prompt Strategies

# slide 2
Problems
Problem
•Generative AI output quality depends heavily on how the prompt is designed.
•Vague prompts may produce relevant content but with weaker structure and 
completeness.
•More specific prompts can guide the AI toward clearer, more useful, and 
better-organized results.
•This experiment tests how different prompt strategies affect the quality of the 
same travel-planning task.
Experi

# slide 3
Experiment Design
• Same AI Model
• Same Input
• Same Use Case
• Different Prompt Strategies

# slide 4
Prompt Strategies
•Zero-shot: Direct instruction without examples.
•Few-shot: Instruction supported by examples.
•Refined Prompt: Detailed instructions with clear structure and 
constraints

# slide 5
Results
Criterion            Zero-Shot    Few-Shot    Refined
 
Relevance               4/5          4/5        5/5

Completeness            4/5          3/5        5/5

Structure               3/5          4/5        5/5

Constraint Adherence    3/5          4/5        5/5

Usefulness              3/5          4/5        5/5

Total                   17/25       19/25       25/25

Key Result
Refined Prompt achieved the highest score: 25/25

# slide 6
Evidence
Zero-Shot
•Detailed itinerary with morning, afternoon, and evening activities.
•Relevant content, but the output was more dense and less scannable. 
Few-Shot
•More consistent formatting and structure.
•Followed the style of the provided examples.
•Some logistical and budget details were missing.
Refined Prompt
•Clear Markdown table covering all required information.
•Included transportation and budget strategies.
•Best organized and most actionable output.

# slide 7
Conclusion
•Prompt design has a strong impact on Generative AI output quality.
•Zero-Shot:Relevant, but less structured.
•Few-Shot:Better consistency and formatting.
•Refined Prompt:Highest quality and strongest constraint adherence.
•Best Prompt:Refined Prompt —25/25.
•Clear instructions, structure, and constraints produced a more useful output.
What We Learned
Better prompts → Better, clearer, and more actionable AI outputs.
